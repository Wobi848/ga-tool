# SIA 386.110 — Gebäudeautomation Schweizer Norm

Die **SIA 386.110** ist die massgebende Schweizer Norm für Gebäudeautomation (GA). Sie definiert Anforderungen an Planung, Ausführung, Inbetriebnahme und Betrieb von GA-Systemen in der Schweiz.

## Überblick

Die SIA 386.110 ist Teil der SIA 386er Serie:

| Norm            | Thema                                                |
| --------------- | ---------------------------------------------------- |
| SIA 386.100     | Gebäudeautomation — Allgemeines (Grundlagen)         |
| **SIA 386.110** | **Gebäudeautomation — Anforderungen und Ausführung** |
| SIA 386.120     | Gebäudeautomation — Qualitätssicherung               |

---

## Effizienzklassen (analog EN 15232)

Die SIA 386.110 übernimmt das Effizienzklassen-Konzept der EN 15232:

| Klasse | Bezeichnung       | Beschreibung                                     |
| ------ | ----------------- | ------------------------------------------------ |
| **A**  | Hochautomatisiert | Prädiktive Regelung, kontinuierliche Optimierung |
| **B**  | Erweitert         | Bedarfsgeführte Regelung, Zonensteuerung         |
| **C**  | Standard          | Normaler GA-Stand (Pflicht-Mindestanforderung)   |
| **D**  | Keine GA          | Manuelle Steuerung, keine Automatik              |

**Anforderung CH:** Für beheizte Gebäude über einem bestimmten Schwellenwert ist Klasse B oder A vorgeschrieben (je nach Kanton und Gebäudekategorie).

**Minergie-Anforderung:** Minergie-P und Minergie-A verlangen Klasse A GA.

## Planungsanforderungen

### Phasen nach SIA 386.110

Die Norm beschreibt den GA-Planungsprozess in Anlehnung an die SIA-Leistungsphasen:

| Phase          | Inhalt GA                                     |
| -------------- | --------------------------------------------- |
| Vorstudie      | GA-Konzept, Effizienzklasse festlegen         |
| Vorprojekt     | Systemgrenzen, Protokolle, Schnittstellen     |
| Bauprojekt     | Datenpunktliste (DPL), Schemen, Gerätewahl    |
| Ausschreibung  | Leistungsbeschrieb GA, Qualitätsanforderungen |
| Ausführung     | Verdrahtung, Parametrierung, Tests            |
| Inbetriebnahme | IBN-Protokoll, Abnahme nach Norm              |
| Betrieb        | Übergabe, Dokumentation, Schulung             |

## Datenpunkt-Anforderungen

Die SIA 386.110 definiert **Mindestdatenpunkte** für verschiedene Anlagentypen:

### Beispiel: Wärmeerzeuger (Heizkörper-Heizung)

**Pflicht-Datenpunkte:**

- Vorlauftemperatur Ist
- Rücklauftemperatur Ist
- Vorlauftemperatur Soll
- Betriebszustand (EIN/AUS)
- Störmeldung
- Betriebsstunden

**Optionale Datenpunkte (für Klasse A/B):**

- Wärmemenge
- Leistung
- Brennerstunden

---

## IBN und Abnahme nach SIA 386.110

Die Norm definiert was bei der Inbetriebnahme zu prüfen ist:

### Abnahme-Pflicht

1. **Dokumentation:** Vollständige DPL, As-Built-Pläne vorhanden
2. **Datenpunkt-Prüfung:** Jeder DPL-Eintrag verifiziert (Messwert stimmt)
3. **Funktionsprüfung:** Regelkreise einzeln prüfen
4. **Alarmprüfung:** Alle Alarme auslösen und quittieren
5. **Zeitprogramm:** Alle Programme testen
6. **Schnittstellen:** Kommunikation GLT↔DDC und DDC↔Feldgeräte

### IBN-Protokoll (Pflicht)

```
Inhalt Pflicht:
  - Gewerk / Anlage
  - Datenpunktliste mit Status (Tested / OK)
  - Messwerte der Prüfung
  - Datum, Unterschrift Inbetriebnehmer
  - Unterschrift Bauherrschaft (Abnahme)
  - Offene Punkte (Mängelliste)
```

**SIA 386.110** is the definitive Swiss standard for building automation (BA). It defines requirements for planning, execution, commissioning, and operation of BA systems in Switzerland.

## Overview

SIA 386.110 is part of the SIA 386 series:

| Standard        | Topic                                                |
| --------------- | ---------------------------------------------------- |
| SIA 386.100     | Building automation — General (fundamentals)         |
| **SIA 386.110** | **Building automation — Requirements and execution** |
| SIA 386.120     | Building automation — Quality assurance              |

---

## Efficiency Classes (analogous to EN 15232)

SIA 386.110 adopts the efficiency class concept from EN 15232:

| Class | Designation      | Description                                 |
| ----- | ---------------- | ------------------------------------------- |
| **A** | Highly automated | Predictive control, continuous optimisation |
| **B** | Advanced         | Demand-driven control, zone control         |
| **C** | Standard         | Normal BA level (mandatory minimum)         |
| **D** | No BA            | Manual control, no automation               |

**Swiss requirement:** For heated buildings above a certain threshold, Class B or A is required (depending on canton and building category).

**Minergie requirement:** Minergie-P and Minergie-A require Class A BA.

---

## Planning Requirements

### Phases per SIA 386.110

The standard describes the BA planning process aligned with SIA service phases:

| Phase              | BA content                                          |
| ------------------ | --------------------------------------------------- |
| Preliminary study  | BA concept, define efficiency class                 |
| Preliminary design | System boundaries, protocols, interfaces            |
| Design             | Data point list (DPL), schematics, device selection |
| Tender             | BA specification, quality requirements              |
| Construction       | Wiring, parameterisation, testing                   |
| Commissioning      | Commissioning record, acceptance per standard       |
| Operation          | Handover, documentation, training                   |

---

## Data Point Requirements

SIA 386.110 defines **minimum data points** for various plant types:

### Example: Heat Generator (Radiator Heating)

**Mandatory data points:**

- Supply temperature actual
- Return temperature actual
- Supply temperature setpoint
- Operating status (ON/OFF)
- Fault signal
- Operating hours

**Optional data points (for Class A/B):**

- Heat quantity
- Power
- Burner hours

---

## Commissioning and Acceptance per SIA 386.110

The standard defines what must be verified during commissioning:

### Mandatory Acceptance Items

1. **Documentation:** Complete DPL and as-built drawings present
2. **Data point verification:** Every DPL entry verified (measured value correct)
3. **Function test:** Control loops tested individually
4. **Alarm test:** All alarms triggered and acknowledged
5. **Time schedule:** All schedules tested
6. **Interfaces:** Communication BMS↔DDC and DDC↔field devices

### Commissioning Record (Mandatory)

```
Mandatory contents:
  - Trade / plant
  - Data point list with status (Tested / OK)
  - Measured values from testing
  - Date, signature of commissioning engineer
  - Signature of client (acceptance)
  - Open items (defect list)
```
