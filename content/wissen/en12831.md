# EN 12831 — Heizlastberechnung

EN 12831 definiert das Verfahren zur Berechnung des Norm-Heizwärmebedarfs (Heizlast) eines Gebäudes oder Raumes. Das Ergebnis bestimmt die Auslegung von Heizflächen, Heizkörpern und Wärmeerzeugern.

## Grundgleichung

```
Φ_HL = Φ_T + Φ_V + Φ_RH

Φ_HL:  Norm-Heizlast [W]
Φ_T:   Transmissions-Wärmeverluste [W]
Φ_V:   Lüftungs-Wärmeverluste [W]
Φ_RH:  Aufheiz-Zuschlag [W] (bei Absenkbetrieb)
```

---

## Transmissionsverluste

```
Φ_T = Σ (A × U × (T_i − T_e))   [W]

A:    Bauteilfläche [m²]
U:    Wärmedurchgangskoeffizient [W/(m²K)]
T_i:  Innentemperatur [°C] (nach Nutzung, z.B. 20 °C)
T_e:  Normaussentemperatur [°C] (standortabhängig)

Korrekturfaktoren:
  - f_u: benachbarte unbeheizte Räume (z.B. Keller, Garage)
  - b_w: erdberührende Bauteile (Boden, Kellerdecke)
```

**U-Wert-Richtwerte (Neubau / Minergie):**

| Bauteil                | U-Wert Bestand | U-Wert Neubau | Minergie |
| ---------------------- | -------------- | ------------- | -------- |
| Aussenwand (Mauerwerk) | 0.5–1.5        | 0.15–0.25     | ≤ 0.15   |
| Dach / oberste Decke   | 0.3–0.8        | 0.12–0.20     | ≤ 0.12   |
| Fenster (2-fach)       | 2.8–3.5        | —             | —        |
| Fenster (3-fach)       | 0.8–1.2        | 0.8–1.2       | ≤ 0.8    |
| Kellerdecke            | 0.5–1.0        | 0.15–0.25     | ≤ 0.15   |

---

## Lüftungsverluste

```
Φ_V = ρ × cp × V̇ × (T_i − T_e)

ρ:    Luftdichte = 1.2 kg/m³
cp:   spez. Wärmekapazität Luft = 1005 J/(kg·K)
V̇:   Luftvolumenstrom [m³/s]

Vereinfacht:
  Φ_V = 0.34 × V̇_l/h × (T_i − T_e)
  V̇_l/h: Luftwechsel [m³/h]

  Natürliche Lüftung: 0.3–1.0 Luftwechsel/h (dicht gebaut: 0.3)
  Mechanische Lüftung: gemäss Planung
```

## Aufheiz-Zuschlag

Bei Absenkbetrieb (Nacht/Wochenende) wird ein Zuschlag berücksichtigt:

```
Φ_RH = f_RH × A_Fussboden

f_RH: Aufheiz-Zuschlagsfaktor [W/m²] abhängig von:
  - Absenkzeit (8h, 16h, 24h)
  - Gebäudeart (leicht, schwer)

Typische Werte:
  Leichtbau (8h Absenkung):  f_RH = 11 W/m²
  Massivbau (8h Absenkung):  f_RH = 6 W/m²
  Massivbau (16h Absenkung): f_RH = 11 W/m²
```

## Praxisbeispiel Heizlast Raum

```
Büro: 4 × 5 m = 20 m², Höhe 2.8 m, T_i = 21 °C, T_e = −8 °C

Transmissionsverluste:
  Aussenwand (10 m², U = 0.20):  10 × 0.20 × 29 = 58 W
  Fenster (3 m², U = 0.90):       3 × 0.90 × 29 = 78 W
  Decke (20 m², U = 0.15):       20 × 0.15 × 29 = 87 W
  Innenwände (innen, ΔT ≈ 0):         ≈ 0 W
  Φ_T = 58 + 78 + 87 = 223 W

Lüftungsverluste (0.4 LW/h):
  V̇ = 20 × 2.8 × 0.4 = 22.4 m³/h
  Φ_V = 0.34 × 22.4 × 29 = 221 W

Norm-Heizlast:
  Φ_HL = 223 + 221 = 444 W → ca. 22 W/m²
```

**Richtwerte Heizlast (gut gedämmtes Gebäude):**

| Gebäudetyp         | Heizlast [W/m²] |
| ------------------ | --------------- |
| Neubau (Minergie)  | 10–20           |
| Neubau (Standard)  | 25–40           |
| Sanierter Altbau   | 40–60           |
| Unsanierter Altbau | 80–120          |

## Anwendung in der GA

```
Heizlast → Auslegung Wärmeerzeuger (WP, Kessel):
  Σ Φ_HL aller Räume = Gebäude-Heizlast
  Zuschlag 10–20 % für Verluste Verteilung

  → Nennleistung Heizanlage
  → Spreizung und Volumenstrom Heizkreise
  → Pumpenauslegung (Δp, Volumenstrom)
  → Ventil-Kv-Wert Berechnung
```

EN 12831 defines the procedure for calculating the design heat load of a building or room. The result determines the sizing of heat emitters, radiators, and heat generators.

## Basic Formula

```
Φ_HL = Φ_T + Φ_V + Φ_RH

Φ_HL:  Design heat load [W]
Φ_T:   Transmission heat losses [W]
Φ_V:   Ventilation heat losses [W]
Φ_RH:  Reheat addition [W] (for setback operation)
```

---

## Transmission Losses

```
Φ_T = Σ (A × U × (T_i − T_e))   [W]

A:    Component area [m²]
U:    Thermal transmittance [W/(m²K)]
T_i:  Indoor temperature [°C] (per use, e.g. 20 °C)
T_e:  Design outdoor temperature [°C] (location-dependent)

Correction factors:
  - f_u: adjacent unheated spaces (e.g. basement, garage)
  - b_w: ground-adjacent components (floor, basement ceiling)
```

**U-value reference values (new build / Minergie):**

| Component                | U-value existing | U-value new build | Minergie |
| ------------------------ | ---------------- | ----------------- | -------- |
| External wall (masonry)  | 0.5–1.5          | 0.15–0.25         | ≤ 0.15   |
| Roof / top floor ceiling | 0.3–0.8          | 0.12–0.20         | ≤ 0.12   |
| Window (double glazing)  | 2.8–3.5          | —                 | —        |
| Window (triple glazing)  | 0.8–1.2          | 0.8–1.2           | ≤ 0.8    |
| Basement ceiling         | 0.5–1.0          | 0.15–0.25         | ≤ 0.15   |

---

## Ventilation Losses

```
Φ_V = ρ × cp × V̇ × (T_i − T_e)

ρ:    Air density = 1.2 kg/m³
cp:   Specific heat capacity of air = 1005 J/(kg·K)
V̇:   Air volume flow [m³/s]

Simplified:
  Φ_V = 0.34 × V̇_ac/h × (T_i − T_e)
  V̇_ac/h: air changes [m³/h]

  Natural ventilation: 0.3–1.0 air changes/h (tight construction: 0.3)
  Mechanical ventilation: per design
```

## Reheat Addition

For setback operation (night/weekend), an addition is included:

```
Φ_RH = f_RH × A_floor

f_RH: Reheat addition factor [W/m²] depending on:
  - Setback duration (8 h, 16 h, 24 h)
  - Building type (lightweight, heavyweight)

Typical values:
  Lightweight construction (8 h setback):  f_RH = 11 W/m²
  Heavyweight construction (8 h setback):  f_RH = 6 W/m²
  Heavyweight construction (16 h setback): f_RH = 11 W/m²
```

---

## Practical Example — Room Heat Load

```
Office: 4 × 5 m = 20 m², height 2.8 m, T_i = 21 °C, T_e = −8 °C

Transmission losses:
  External wall (10 m², U = 0.20):  10 × 0.20 × 29 = 58 W
  Window (3 m², U = 0.90):           3 × 0.90 × 29 = 78 W
  Ceiling (20 m², U = 0.15):        20 × 0.15 × 29 = 87 W
  Internal walls (internal, ΔT ≈ 0):     ≈ 0 W
  Φ_T = 58 + 78 + 87 = 223 W

Ventilation losses (0.4 ac/h):
  V̇ = 20 × 2.8 × 0.4 = 22.4 m³/h
  Φ_V = 0.34 × 22.4 × 29 = 221 W

Design heat load:
  Φ_HL = 223 + 221 = 444 W → approx. 22 W/m²
```

**Reference values for heat load (well-insulated building):**

| Building type                   | Heat load [W/m²] |
| ------------------------------- | ---------------- |
| New build (Minergie)            | 10–20            |
| New build (standard)            | 25–40            |
| Refurbished existing building   | 40–60            |
| Unrefurbished existing building | 80–120           |

## Application in BA

```
Heat load → sizing of heat generator (HP, boiler):
  Σ Φ_HL of all rooms = building heat load
  Add 10–20 % for distribution losses

  → Rated output of heating system
  → Spread and volume flow of heating circuits
  → Pump sizing (Δp, volume flow)
  → Valve Kv calculation
```
