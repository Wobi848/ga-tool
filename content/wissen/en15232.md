# EN 15232 — GA-Effizienzklassen A–D

Die **EN 15232** (jetzt EN ISO 52120) definiert einen Rahmen zur Bewertung des Einflusses von Gebäudeautomation und Gebäudeleittechnik (GA/GLT) auf die Energieeffizienz von Gebäuden. Sie gibt Energiespar-Faktoren für verschiedene Effizienzklassen an.

## Die vier Effizienzklassen

| Klasse | Bezeichnung         | Beschreibung                                            |
|--------|---------------------|---------------------------------------------------------|
| **A**  | High Energy Performance | Hochautomatisiertes Gebäude, kontinuierliche Optimierung |
| **B**  | Advanced            | Erweiterte GA, bedarfsgeführte Regelung                 |
| **C**  | Standard            | Standard GA nach aktuellen Normen                       |
| **D**  | Non Energy Efficient | Keine oder veraltete GA, manuelle Steuerung             |

> **Klasse C** gilt als Referenz (100 %). Klasse D verschwendet Energie, Klasse A und B sparen gegenüber C.

---

## Einsparpotenziale nach Gebäudetyp

### Bürogebäude

| Klasse | Heizung | Kühlung | Lüftung | Beleuchtung |
|--------|---------|---------|---------|-------------|
| **A**  | −10 %   | −25 %   | −35 %   | −45 %       |
| **B**  | −6 %    | −15 %   | −20 %   | −25 %       |
| **C**  | 0 %     | 0 %     | 0 %     | 0 %         |
| **D**  | +51 %   | +124 %  | +94 %   | +43 %       |

### Wohngebäude

| Klasse | Heizung | Kühlung | Lüftung | Warmwasser |
|--------|---------|---------|---------|------------|
| **A**  | −8 %    | −25 %   | −35 %   | −10 %      |
| **B**  | −4 %    | −15 %   | −20 %   | −5 %       |
| **C**  | 0 %     | 0 %     | 0 %     | 0 %        |
| **D**  | +28 %   | +68 %   | +34 %   | +5 %       |

**Fazit:** Ein Bürogebäude mit Klasse D verbraucht bis zu **doppelt so viel** wie dasselbe Gebäude mit Klasse C. Klasse A spart nochmals 25–35 % gegenüber C.

## BACS-Faktor (BAC-Faktor)

Die Norm definiert **BACS-Faktoren** (Building Automation and Control System) für die vereinfachte Berechnung:

```
Ef_BACS = Ef_Ref × fBACS
```

| Gebäudetyp  | Klasse A | Klasse B | Klasse C | Klasse D |
|-------------|----------|----------|----------|----------|
| Büro        | 0.80     | 0.90     | 1.00     | 1.51     |
| Wohngebäude | 0.88     | 0.94     | 1.00     | 1.10     |

*Faktor < 1 = besser als Referenz (Klasse C)*

---

## TBS — Technische Gebäudesystemsteuerung

EN 15232 / EN ISO 52120 unterscheidet zwischen:

- **BACS** — Building Automation and Control System (klassische GA/GLT)
- **TBS** — Technical Building Systems (Anlagenregelung: Pumpen, FUs, Ventile)

Beide wirken auf die Energieeffizienz — TBS oft stärker als BACS.

---

## Umsetzungsbeispiele je Klasse

### Von D nach C (grösste Wirkung!)

- Zeitprogramme einrichten (Nachtabsenkung, Wochenende AUS)
- Abschaltung wenn Gebäude leer (Ferienmodus)
- Raumtemperatur-Regelung statt manuell
- Lüftung nach Zeitplan statt Dauerbelüftung

### Von C nach B

- CO₂-geführte Lüftung (VAV statt CAV)
- Präsenzsteuerung Beleuchtung
- Raumweise Heizungsregelung (statt gesamtes Stockwerk)
- Optimierter Heizbetrieb (Aufheizoptimierung)

### Von B nach A

- Prädiktive Regelung (Wetterprognose nutzen)
- Kontinuierliche Optimierung via GLT-Analytics
- Automatische Einregulierung Hydraulik
- Demand Response (Lastmanagement)
- Gebäude-weite Energieoptimierung (EMS)

**EN 15232** (now EN ISO 52120) defines a framework for assessing the influence of building automation and building management systems (BA/BMS) on the energy efficiency of buildings. It specifies energy-saving factors for different efficiency classes.

## The Four Efficiency Classes

| Class | Name | Description |
|-------|------|------------|
| **A** | High Energy Performance | Highly automated building, continuous optimisation |
| **B** | Advanced | Extended BA, demand-controlled regulation |
| **C** | Standard | Standard BA per current codes |
| **D** | Non Energy Efficient | No or outdated BA, manual control |

> **Class C** is the reference (100%). Class D wastes energy; Classes A and B save compared to C.

---

## Savings Potential by Building Type

### Office Buildings

| Class | Heating | Cooling | Ventilation | Lighting |
|-------|---------|---------|------------|---------|
| **A** | −10% | −25% | −35% | −45% |
| **B** | −6% | −15% | −20% | −25% |
| **C** | 0% | 0% | 0% | 0% |
| **D** | +51% | +124% | +94% | +43% |

### Residential Buildings

| Class | Heating | Cooling | Ventilation | DHW |
|-------|---------|---------|------------|-----|
| **A** | −8% | −25% | −35% | −10% |
| **B** | −4% | −15% | −20% | −5% |
| **C** | 0% | 0% | 0% | 0% |
| **D** | +28% | +68% | +34% | +5% |

**Conclusion:** An office building with Class D uses up to **twice as much** energy as the same building with Class C. Class A saves a further 25–35% compared to C.

## BACS Factor (BAC Factor)

The standard defines **BACS factors** (Building Automation and Control System) for simplified calculation:

```
Ef_BACS = Ef_Ref × fBACS
```

| Building type | Class A | Class B | Class C | Class D |
|--------------|---------|---------|---------|---------|
| Office | 0.80 | 0.90 | 1.00 | 1.51 |
| Residential | 0.88 | 0.94 | 1.00 | 1.10 |

*Factor < 1 = better than reference (Class C)*

---

## TBS — Technical Building System Controls

EN 15232 / EN ISO 52120 distinguishes between:

- **BACS** — Building Automation and Control System (conventional BA/BMS)
- **TBS** — Technical Building Systems (plant control: pumps, VSDs, valves)

Both affect energy efficiency — TBS often more than BACS.

---

## Implementation Examples per Class

### From D to C (greatest impact!)

- Set up time schedules (night setback, weekend off)
- Switch off when building is empty (holiday mode)
- Room temperature control instead of manual
- Ventilation on schedule instead of continuous

### From C to B

- CO₂-controlled ventilation (VAV instead of CAV)
- Presence-based lighting control
- Room-by-room heating control (instead of whole floor)
- Optimised heating (start optimisation)

### From B to A

- Predictive control (use weather forecast)
- Continuous optimisation via BMS analytics
- Automatic hydraulic balancing
- Demand response (load management)
- Building-wide energy optimisation (EMS)
