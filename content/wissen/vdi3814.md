# VDI 3814 — MSR-Technik in der Gebäudeautomation

VDI 3814 ist die zentrale deutsche Richtlinie für MSR- und Gebäudeautomations-Technik. Sie beschreibt Planung, Ausführung, IBN und Betrieb von GA-Systemen.

## VDI 3814-1: Grundlagen und Systemstruktur

### Drei-Ebenen-Modell

```
Ebene 3: Management (GLT / SCADA)
  - Visualisierung, Alarme, Berichte, Fernzugriff
  - Zeitprogramme, Sollwert-Vorgaben
  
Ebene 2: Automation (DDC / Feldbus)
  - PID-Regelung, Logiken, Programm
  - Kommunikation Feld ↔ GLT
  
Ebene 1: Feld (Sensoren, Aktoren)
  - Temperatursensoren, Ventile, Pumpen
  - Direkte physikalische Schnittstellen
```

### Begriffe nach VDI 3814

| Begriff              | Definition                                              |
|----------------------|---------------------------------------------------------|
| Datenpunkt (DP)      | Logische Informationseinheit (Wert, Typ, Adresse)       |
| Messstelle (MS)      | Physikalische Messstelle im Feld                        |
| Stellglied (SG)      | Aktor zum Stellen einer Regelgrösse                     |
| Regelkreis           | Sensor + Regler + Stellglied + Strecke                  |
| Betriebsart          | Definiierter Anlagenzustand (Normal, Hand, Störung)     |
| Sollwertführung      | Anpassung des Sollwerts an Einflussgrößen (Wetter etc.) |

## VDI 3814-2: Planung und Ausschreibung

### Leistungsphasen GA (angelehnt an HOAI)

```
LP 1: Grundlagenermittlung
  - Anforderungen, Gebäudekonzept, Normen

LP 2: Vorplanung
  - Systemauswahl (BACnet, KNX, etc.)
  - Erste Datenpunktschätzung

LP 3: Entwurfsplanung
  - Systemkonzept, Gewerke-Schnittstellen
  - Datenpunktliste (grob)

LP 4: Genehmigungsplanung
  - (selten relevant für GA)

LP 5: Ausführungsplanung
  - DPL vollständig
  - Funktionsbeschreibung
  - Schemen (MSR-Schema)
  - Ausschreibungsunterlagen

LP 6–9: Ausschreibung, Vergabe, Bauüberwachung, IBN
```

### Ausschreibungs-Grundsätze

```
Leistungsverzeichnis GA muss enthalten:
  1. Systemanforderungen (Protokoll, Hierarchie)
  2. Datenpunktliste (als Grundlage für Offertkalkulation)
  3. Funktionsbeschreibungen je Anlage
  4. IBN-Anforderungen (was wird geprüft)
  5. Dokumentations-Anforderungen (As-Built, Backup)
  6. Wartungs-/Unterhaltsanforderungen
```

## VDI 3814-4: Visualisierung

### Symbol-Grundsätze

```
Normsymbole VDI 3814-4:
  
  Pumpe:          Kreis mit Dreieck (Strömungsrichtung)
  2-Wege-Ventil:  Bowtie-Symbol ►◄
  3-Wege-Ventil:  T-Bowtie-Symbol
  Wärmetauscher:  Schlangensymbol im Kreis
  Ventilator:     Kreis mit Flügelrad
  Filter:         Rechteck mit Schraffur
```

### Farbcodes

```
Grün:   Betrieb normal (EIN, aktiv, OK)
Rot:    Störung, Alarm, Fehler
Gelb:   Handbetrieb, Warnung
Grau:   Ausgeschaltet, inaktiv
Blau:   Kälte, Kaltwassernetz
Orange: Wärme, Heizungsnetz
```
