# VDI 3814 — MSR-Technik in der Gebäudeautomation

VDI 3814 ist die zentrale deutsche Richtlinie für MSR- und Gebäudeautomations-Technik. Sie beschreibt Planung, Ausführung, IBN und Betrieb von GA-Systemen.

## VDI 3814-1: Grundlagen und Systemstruktur

### Drei-Ebenen-Modell

```
Ebene 3: Management (GLT / SCADA)
  - Visualisierung, Alarme, Berichte, Fernzugriff
  - Zeitprogramme, Sollwert-Vorgaben
  
Ebene 2: Automation (DDC / Feldbus)
  - PID-Regelung, Logiken, Programm
  - Kommunikation Feld ↔ GLT
  
Ebene 1: Feld (Sensoren, Aktoren)
  - Temperatursensoren, Ventile, Pumpen
  - Direkte physikalische Schnittstellen
```

### Begriffe nach VDI 3814

| Begriff              | Definition                                              |
|----------------------|---------------------------------------------------------|
| Datenpunkt (DP)      | Logische Informationseinheit (Wert, Typ, Adresse)       |
| Messstelle (MS)      | Physikalische Messstelle im Feld                        |
| Stellglied (SG)      | Aktor zum Stellen einer Regelgrösse                     |
| Regelkreis           | Sensor + Regler + Stellglied + Strecke                  |
| Betriebsart          | Definiierter Anlagenzustand (Normal, Hand, Störung)     |
| Sollwertführung      | Anpassung des Sollwerts an Einflussgrößen (Wetter etc.) |

## VDI 3814-2: Planung und Ausschreibung

### Leistungsphasen GA (angelehnt an HOAI)

```
LP 1: Grundlagenermittlung
  - Anforderungen, Gebäudekonzept, Normen

LP 2: Vorplanung
  - Systemauswahl (BACnet, KNX, etc.)
  - Erste Datenpunktschätzung

LP 3: Entwurfsplanung
  - Systemkonzept, Gewerke-Schnittstellen
  - Datenpunktliste (grob)

LP 4: Genehmigungsplanung
  - (selten relevant für GA)

LP 5: Ausführungsplanung
  - DPL vollständig
  - Funktionsbeschreibung
  - Schemen (MSR-Schema)
  - Ausschreibungsunterlagen

LP 6–9: Ausschreibung, Vergabe, Bauüberwachung, IBN
```

### Ausschreibungs-Grundsätze

```
Leistungsverzeichnis GA muss enthalten:
  1. Systemanforderungen (Protokoll, Hierarchie)
  2. Datenpunktliste (als Grundlage für Offertkalkulation)
  3. Funktionsbeschreibungen je Anlage
  4. IBN-Anforderungen (was wird geprüft)
  5. Dokumentations-Anforderungen (As-Built, Backup)
  6. Wartungs-/Unterhaltsanforderungen
```

## VDI 3814-1: Fundamentals and System Structure

### Three-Level Model

```
Level 3: Management (BMS / SCADA)
  - Visualisation, alarms, reports, remote access
  - Time schedules, setpoint inputs
  
Level 2: Automation (DDC / fieldbus)
  - PID control, logic, programming
  - Communication field ↔ BMS
  
Level 1: Field (sensors, actuators)
  - Temperature sensors, valves, pumps
  - Direct physical interfaces
```

### Terms per VDI 3814

| Term | Definition |
|------|-----------|
| Data point (DP) | Logical information unit (value, type, address) |
| Measuring point (MP) | Physical measurement location in the field |
| Final control element | Actuator for adjusting the controlled variable |
| Control loop | Sensor + controller + actuator + plant |
| Operating mode | Defined plant state (normal, manual, fault) |
| Setpoint compensation | Adjustment of setpoint to influencing variables (weather etc.) |

## VDI 3814-2: Planning and Tendering

### BA Service Phases (based on HOAI)

```
SP 1: Establishing requirements
  - Requirements, building concept, codes

SP 2: Preliminary design
  - System selection (BACnet, KNX, etc.)
  - First data point estimate

SP 3: Design development
  - System concept, trade interfaces
  - Data point list (outline)

SP 4: Approval planning
  - (rarely relevant for BA)

SP 5: Detailed design
  - Complete data point list
  - Functional description
  - Schematics (P&ID)
  - Tender documents

SP 6–9: Tendering, award, site supervision, commissioning
```

### Tendering Principles

```
Bill of quantities for BA must include:
  1. System requirements (protocol, hierarchy)
  2. Data point list (basis for tender calculation)
  3. Functional descriptions per plant
  4. Commissioning requirements (what is tested)
  5. Documentation requirements (as-built, backup)
  6. Maintenance/service requirements
```

### Symbol Principles

```

  Filter:         Rectangle with hatching
```

### Colour Codes

```
Green:  Normal operation (ON, active, OK)
Red:    Fault, alarm, error
Yellow: Manual mode, warning
Grey:   Switched off, inactive
Blue:   Cooling, chilled water network
Orange: Heating, hot water network
```
