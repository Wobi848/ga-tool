# IEC 61850 — Kommunikation in der Energieverteilung

IEC 61850 ist der internationale Standard für die Kommunikation in **elektrischen Mittelspannungs- und Hochspannungsanlagen, Schalttafeln und Unterwerken**. Er gewinnt zunehmend Bedeutung in der Gebäudeautomation, da moderne Energiemanagement-Systeme, dezentrale Erzeuger (PV, BHKW) und intelligente Schaltanlagen immer öfter IEC-61850-Schnittstellen bieten.

---

## Wofür IEC 61850?

In Gebäuden taucht IEC 61850 auf bei:

- **Mittelspannungsanlagen** (z.B. Schutzrelais Siemens 7SJ, ABB REF615)
- **Einspeisepunkten** mit Schutzfunktionen (Distanzschutz, Erdschlussrichtungsrelais)
- **BHKW und Blockheizkraftwerke** mit Leistungsregelung
- **Photovoltaikanlagen** (Wechselrichter mit IEC 61850-7-420)
- **Batteriespeichersysteme** (BESS)
- **Ladeinfrastruktur** (Elektromobilität, Lastmanagement)
- **Smart-Grid-Anbindungen** (Netzdienstleistungen, Regelenergie)

---

## Architektur und Konzepte

### IED — Intelligent Electronic Device

Ein IED ist ein intelligentes Feldgerät: Schutzrelais, Messumformer, Leistungsschalter-Controller. Jedes IED enthält logische Knoten (Logical Nodes).

### Logical Nodes (LN)

Logical Nodes sind standardisierte Funktionsblöcke, die bestimmte Gerätefunktionen repräsentieren:

| Logical Node | Bedeutung                       |
| ------------ | ------------------------------- |
| XCBR         | Leistungsschalter               |
| XSWI         | Trennschalter                   |
| MMXU         | Messung (U, I, P, Q, f)         |
| PDIF         | Differentialschutz              |
| PDIS         | Distanzschutz                   |
| PTOC         | Überstromschutz                 |
| GGIO         | Allgemeine digitale/analoge E/A |
| DRCC         | Dezentrale Erzeugungsregelung   |
| MMTR         | Zählung (kWh, kvarh)            |

### Logical Devices (LD)

Ein IED kann mehrere Logical Devices enthalten (z.B. Messung, Schutz, Steuerung).

---

## Kommunikationsdienste

### MMS (Manufacturing Message Specification)

Für SCADA-Anbindung und Konfiguration über TCP/IP:

- Lesen/Schreiben von Datenpunkten
- Berichte (Reports) bei Zustandsänderungen
- Logs (historische Daten)
- Steuerung (Control)

### GOOSE (Generic Object Oriented Substation Events)

Für schnelle Peer-to-Peer-Kommunikation zwischen IEDs (Ethernet, kein TCP/IP):

- Latenz < 4 ms
- Schutzauslösungen, Verriegelungen
- Multicast (alle Teilnehmer im VLAN empfangen)

### Sampled Values (SV)

Für Echtzeitübertragung von Messwerten (Strom, Spannung) mit hoher Abtastrate:

- Typisch 80 oder 256 Abtastwerte pro Netzperiode (50 Hz)
- Für Schutzfunktionen und Qualitätsüberwachung
- Ersetzt analoge Messumformer-Verdrahtung

## Konfigurationssprache SCL

IEC 61850 definiert eine XML-basierte **Substation Configuration Language (SCL)** für die Engineering-Daten:

| Dateiendung | Inhalt                                              |
| ----------- | --------------------------------------------------- |
| `.icd`      | IED Capability Description (Gerätebeschreibung)     |
| `.cid`      | Configured IED Description (konfiguriertes Gerät)   |
| `.scd`      | Substation Configuration Description (Gesamtanlage) |
| `.iid`      | Instantiated IED Description                        |

## Netzwerk-Anforderungen

IEC 61850 läuft über **Ethernet (IEEE 802.3)**:

| Dienst         | Layer           | Protokoll                     |
| -------------- | --------------- | ----------------------------- |
| MMS            | 7 (Application) | TCP/IP → MMS                  |
| GOOSE          | 2 (Data Link)   | Ethernet-Multicast (kein IP!) |
| Sampled Values | 2 (Data Link)   | Ethernet-Multicast            |

**GOOSE und SV laufen direkt über Ethernet Layer 2** — Switches dürfen kein Routing durchführen (keine IP-Weiterleitung), aber sie müssen GOOSE-Pakete mit minimaler Latenz weiterleiten. Weil GOOSE kein IP verwendet, hilft IGMP-Snooping nicht. Nötig sind **Managed Switches** mit VLANs und statischen Multicast-Filtern, damit die Telegramme nur dorthin gelangen, wo sie gebraucht werden.

## IEC 61850 in der Gebäudeautomation — Integrationspfade

### Weg 1: OPC-UA als Brücke

Schutzrelais (IEC 61850 MMS) → Gateway oder Server, der IEC 61850 auf OPC UA umsetzt → GLT oder SCADA als OPC UA Client

### Weg 2: Direktanbindung über BACnet-Gateway

Mittelspannungsschaltanlage (IEC 61850) → Gateway IEC 61850 auf BACnet/IP → GLT

### Weg 3: EMS-Integration

IED wie Zähler oder Einspeiserelais → Energiemanagement als IEC-61850-Client → Lastabwurf, Demand Response, PV-Regelung

IEC 61850 is the international standard for communication in **medium-voltage and high-voltage electrical installations, switchgear, and substations**. It is gaining increasing importance in building automation as modern energy management systems, distributed generators (PV, CHP), and intelligent switchgear increasingly offer IEC 61850 interfaces.

---

## Where Is IEC 61850 Used?

In buildings, IEC 61850 appears in:

- **Medium-voltage installations** (e.g. protective relays Siemens 7SJ, ABB REF615)
- **Grid connection points** with protection functions (distance protection, earth-fault directional relay)
- **CHP units** (combined heat and power) with power control
- **Photovoltaic systems** (inverters with IEC 61850-7-420)
- **Battery energy storage systems** (BESS)
- **Charging infrastructure** (e-mobility, load management)
- **Smart grid connections** (grid services, balancing energy)

## Architecture and Concepts

### IED — Intelligent Electronic Device

An IED is an intelligent field device: protective relay, transducer, circuit breaker controller. Each IED contains logical nodes.

### Logical Nodes (LN)

Logical nodes are standardised functional blocks representing specific device functions:

| Logical node | Meaning                             |
| ------------ | ----------------------------------- |
| XCBR         | Circuit breaker                     |
| XSWI         | Disconnector                        |
| MMXU         | Measurement (V, I, P, Q, f)         |
| PDIF         | Differential protection             |
| PDIS         | Distance protection                 |
| PTOC         | Overcurrent protection              |
| GGIO         | General digital/analogue I/O        |
| DRCC         | Distributed energy resource control |
| MMTR         | Metering (kWh, kvarh)               |

### Logical Devices (LD)

An IED may contain multiple logical devices (e.g. measurement, protection, control).

---

## Communication Services

### MMS (Manufacturing Message Specification)

For SCADA connection and configuration over TCP/IP:

- Reading/writing data points
- Reports on state changes
- Logs (historical data)
- Control

### GOOSE (Generic Object Oriented Substation Events)

For fast peer-to-peer communication between IEDs (Ethernet, no TCP/IP):

- Latency < 4 ms
- Protection trips, interlocks
- Multicast (all participants in the VLAN receive)

### Sampled Values (SV)

For real-time transmission of measurements (current, voltage) at high sampling rates:

- Typically 80 or 256 samples per network cycle (50 Hz)
- For protection functions and power quality monitoring
- Replaces analogue transducer wiring

## Network Requirements

IEC 61850 runs over **Ethernet (IEEE 802.3)**:

| Service        | Layer           | Protocol                    |
| -------------- | --------------- | --------------------------- |
| MMS            | 7 (Application) | TCP/IP → MMS                |
| GOOSE          | 2 (Data Link)   | Ethernet multicast (no IP!) |
| Sampled Values | 2 (Data Link)   | Ethernet multicast          |

**GOOSE and SV run directly over Ethernet Layer 2** — switches must not route (no IP forwarding) but must forward GOOSE frames with minimum latency. Because GOOSE does not use IP, IGMP snooping does not help. **Managed switches** with VLANs and static multicast filters are needed so that the frames only reach where they are needed.

## IEC 61850 in Building Automation — Integration Paths

### Path 1: OPC UA as Bridge

Protection relay (IEC 61850 MMS) → gateway or server converting IEC 61850 to OPC UA → BMS or SCADA as OPC UA client

### Path 2: Direct Connection via BACnet Gateway

Medium-voltage switchgear (IEC 61850) → gateway IEC 61850 to BACnet/IP → BMS

### Path 3: EMS Integration

IED such as meter or feed-in relay → energy management as IEC 61850 client → load shedding, demand response, PV control
