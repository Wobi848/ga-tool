# Kältemittel — R32, R410A, R744, R290 im Vergleich

Die Wahl des Kältemittels beeinflusst Effizienz, Sicherheit und Zukunftsfähigkeit einer Anlage. Durch die EU F-Gase-Verordnung werden klassische HFKWs (R410A) schrittweise durch klimafreundlichere Alternativen ersetzt.

## Kältemittel-Klassifikation

**ASHRAE/ISO 817-Kennzeichnung:**

```
R-XYZ
│
├── Einheitliche Nummerierung nach ASHRAE 34
│
Beispiele:
  R-134a: HFKW (Hydrofluorkohlenwasserstoff)
  R-744:  CO₂ (natürliches Kältemittel)
  R-290:  Propan (natürliches Kältemittel, Kohlenwasserstoff)
  R-410A: Gemisch aus R-32 und R-125 (HFKW-Gemisch)
```

### Sicherheitsklassen (ISO 817)

| Klasse | Toxizität | Entflammbarkeit     | Beispiele                   |
| ------ | --------- | ------------------- | --------------------------- |
| A1     | Niedrig   | Nicht entflammbar   | R-410A, R-134a, R-744 (CO₂) |
| A2L    | Niedrig   | Schwach entflammbar | **R-32**, R-452B            |
| A3     | Niedrig   | Hoch entflammbar    | R-290 (Propan), R-600a      |
| B1     | Hoch      | Nicht entflammbar   | R-123                       |

## Die wichtigsten Kältemittel

### R-410A (Phase-Out)

| Parameter           | Wert                                  |
| ------------------- | ------------------------------------- |
| **GWP** (100 Jahre) | **2088** — sehr hoch!                 |
| Sicherheitsklasse   | A1 (nicht entflammbar, nicht toxisch) |
| Druckniveau         | Hoch (~23 bar bei 40 °C Kondensation) |
| Status              | **Phase-Out ab 2025** (EU F-Gase)     |
| Einsatz             | Split-Klimaanlagen, VRF, Wärmepumpen  |

→ Neuanlagen mit R-410A sind in EU ab 2025 verboten.

### R-32

| Parameter         | Wert                                     |
| ----------------- | ---------------------------------------- |
| **GWP**           | **675** — ca. 1/3 von R-410A             |
| Sicherheitsklasse | A2L (schwach entflammbar)                |
| Druckniveau       | Mittel-hoch (~19 bar bei 40 °C)          |
| Status            | Aktuell häufigster **Ersatz** für R-410A |
| Einsatz           | Klimaanlagen (Daikin, Mitsubishi etc.)   |

**A2L-Anforderungen:** Bei R-32 müssen Geräte bestimmte Sicherheitsanforderungen erfüllen (Leckdetektion, belüftete Aufstellung). Servicetechniker brauchen A2L-Schulung.

### R-744 (CO₂)

| Parameter         | Wert                                              |
| ----------------- | ------------------------------------------------- |
| **GWP**           | **1** — natürliches Kältemittel!                  |
| Sicherheitsklasse | A1 (nicht entflammbar, nicht toxisch)             |
| Druckniveau       | Sehr hoch (bis 120 bar transkritisch)             |
| Status            | Zukunftssicher, wächst stark                      |
| Einsatz           | **Wärmepumpen** (bis 90 °C VL!), Supermarkt-Kälte |

**Besonderheit transkritischer Betrieb:** Bei hohen Aussentemperaturen über dem kritischen Punkt (31 °C) läuft der Kreislauf transkritisch — andere Physik als subkritische Kältemittel. Spezielle Komponenten nötig.

**Vorteil WP:** R-744-Wärmepumpen liefern sehr hohe Vorlauftemperaturen (bis 90 °C) — ideal für Altbau-Sanierung.

### R-290 (Propan)

| Parameter         | Wert                               |
| ----------------- | ---------------------------------- |
| **GWP**           | **3** — natürliches Kältemittel!   |
| Sicherheitsklasse | **A3** (hochentflammbar!)          |
| Druckniveau       | Niedrig (~13 bar bei 40 °C)        |
| Status            | Zunehmend, vor allem kleine Geräte |
| Einsatz           | Wärmepumpen (Split), Kühlschränke  |

**Sicherheitsanforderungen A3:** Strenge Aufstellvorschriften (max. Füllmenge je nach Aufstellort), Leckdetektion, explosionssicheres Zubehör. Nicht für jeden Aufstellort geeignet.

## EU F-Gase-Verordnung 517/2014

Die Verordnung schränkt Kältemittel mit hohem GWP schrittweise ein:

| Jahr     | Massnahme                                              |
| -------- | ------------------------------------------------------ |
| 2020     | Phase-Down HFKWs auf 37 % des 2009-Niveaus             |
| 2022     | Verbot R-404A und R-507A (GWP > 2500) für Neuanlagen   |
| **2025** | **Verbot R-410A für Neuanlagen < 3 kW** (ab 2027 alle) |
| 2030     | Phase-Down auf 21 %                                    |
| 2050     | Weitgehende Elimination HFKWs                          |

**Praxis:** R-410A-Servicekältemittel bleibt für Bestandsanlagen verfügbar — aber teurer (Quotenhandel).

The choice of refrigerant affects the efficiency, safety, and long-term viability of a system. The EU F-Gas Regulation is progressively phasing out conventional HFCs (R410A) in favour of lower-GWP alternatives.

## Refrigerant Classification

**ASHRAE/ISO 817 designation:**

```
R-XYZ
│
├── Standardised numbering per ASHRAE 34
│
Examples:
  R-134a: HFC (hydrofluorocarbon)
  R-744:  CO₂ (natural refrigerant)
  R-290:  Propane (natural refrigerant, hydrocarbon)
  R-410A: Blend of R-32 and R-125 (HFC blend)
```

### Safety Classes (ISO 817)

| Class | Toxicity | Flammability     | Examples                    |
| ----- | -------- | ---------------- | --------------------------- |
| A1    | Low      | Non-flammable    | R-410A, R-134a, R-744 (CO₂) |
| A2L   | Low      | Mildly flammable | **R-32**, R-452B            |
| A3    | Low      | Highly flammable | R-290 (propane), R-600a     |
| B1    | High     | Non-flammable    | R-123                       |

## The Key Refrigerants

### R-410A (Phase-Out)

| Parameter           | Value                                   |
| ------------------- | --------------------------------------- |
| **GWP** (100 years) | **2088** — very high!                   |
| Safety class        | A1 (non-flammable, non-toxic)           |
| Pressure level      | High (~23 bar at 40 °C condensing)      |
| Status              | **Phase-out from 2025** (EU F-Gas)      |
| Applications        | Split air conditioners, VRF, heat pumps |

→ New equipment with R-410A is banned in the EU from 2025.

### R-32

| Parameter      | Value                                            |
| -------------- | ------------------------------------------------ |
| **GWP**        | **675** — approx. 1/3 of R-410A                  |
| Safety class   | A2L (mildly flammable)                           |
| Pressure level | Medium-high (~19 bar at 40 °C)                   |
| Status         | Currently most common **replacement** for R-410A |
| Applications   | Air conditioners (Daikin, Mitsubishi, etc.)      |

**A2L requirements:** R-32 equipment must meet specific safety requirements (leak detection, ventilated installation). Service technicians need A2L training.

### R-744 (CO₂)

| Parameter      | Value                                                              |
| -------------- | ------------------------------------------------------------------ |
| **GWP**        | **1** — natural refrigerant!                                       |
| Safety class   | A1 (non-flammable, non-toxic)                                      |
| Pressure level | Very high (up to 120 bar transcritical)                            |
| Status         | Future-proof, growing rapidly                                      |
| Applications   | **Heat pumps** (up to 90 °C flow temp!), supermarket refrigeration |

**Transcritical operation:** At high outdoor temperatures above the critical point (31 °C), the cycle runs transcritically — different physics than subcritical refrigerants. Requires special components.

**Heat pump advantage:** R-744 heat pumps deliver very high flow temperatures (up to 90 °C) — ideal for retrofitting older buildings.

### R-290 (Propane)

| Parameter      | Value                                |
| -------------- | ------------------------------------ |
| **GWP**        | **3** — natural refrigerant!         |
| Safety class   | **A3** (highly flammable!)           |
| Pressure level | Low (~13 bar at 40 °C)               |
| Status         | Growing, especially small appliances |
| Applications   | Heat pumps (split), refrigerators    |

**A3 safety requirements:** Strict installation rules (maximum charge per installation location), leak detection, explosion-proof accessories. Not suitable for all installation environments.

## EU F-Gas Regulation 517/2014

The regulation progressively restricts refrigerants with high GWP:

| Year     | Measure                                                          |
| -------- | ---------------------------------------------------------------- |
| 2020     | Phase-down HFCs to 37% of 2009 baseline                          |
| 2022     | Ban on R-404A and R-507A (GWP > 2500) for new equipment          |
| **2025** | **Ban on R-410A for new equipment < 3 kW** (from 2027 all sizes) |
| 2030     | Phase-down to 21%                                                |
| 2050     | Substantial elimination of HFCs                                  |

**In practice:** R-410A service refrigerant remains available for existing equipment — but at higher cost (quota trading).
